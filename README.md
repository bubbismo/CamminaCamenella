# CamminaCamenella

App Android allegra e rossa per registrare camminate e corse: GPS in background, mappa, dislivello, calorie, fatica percepita e storico. Tutti i dati restano sul telefono: niente account, niente server, niente costi.

> Progetto in costruzione. Fase 1: registrazione e storico. Fase 2: pianificazione del percorso.
